- В предоставленном списке есть пропуски ID и диапазоны, которые нельзя считать заполненными автоматически.
- В исходном сообщении диапазон 13000–13019 был описан, но перечислены только ID 13000–13018.
- Диапазон 14000–14057 был описан, но в подробном списке перечислены только 14000–14037.
